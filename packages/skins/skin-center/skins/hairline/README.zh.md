# 素线

[English](README.md) | 中文

暗色专用的 dsh 皮肤，按制图纸的画法做：界面里的每一根线都是**画出来的，不是填出来的**
—— 1px 墨线、磨砂玻璃面板，水面则由一条连续的墨线交代。背景是一段循环的水面视频。

## 这是什么

- **纯资产**：`skin.json`（v2 清单）+ `skin.css`（完整的 `--dsw-alias-*`
  token 重映射）+ `patches.css`（L3 自由选择器）+ 一段循环 MP4。
  无 package.json、无构建步骤、无 hooks。
- **构造上就是暗色**：调色板同时声明在 `:root` 与 `body[data-ds-dark-theme]` 上，
  每条 L3 规则都去掉了明暗分支，并钉死 `color-scheme: dark`，让原生控件跟着走。
  市场渲染器只注入样式、不跑加载器的 `:root` → `body` token 克隆，所以调色板也声明在
  `body` 上。
- **两种宿主主题都实拍过，不是声明**：提交的两张预览分别来自**浅色宿主**
  （`preview.html?skin=hairline&theme=light`，即不带 `body[data-ds-dark-theme]`）与深色宿主，
  1440×900。把会动的背景隔离掉（隐藏 `<video>`、保留 scrim）之后，两种宿主主题的渲染
  **逐像素完全相同**（1,296,000 个像素中 0 个有差异，最大通道差 0）。两张图作为文件仍然
  不同，只是因为背景是一段循环视频、两次抓拍落在不同的水面上。
- **三处模块 CSS 的浅色分支被钉住了**：`Deliverables`、`JsonTree` 与 `GuideBody`
  按 `body[data-ds-dark-theme]` 分支、直接读 `--dsw-static-*` 静态色阶，浅色方案下会
  被官方浅色值上色。这里用稳定钩子把它们钉回来
  （`[data-presented-files-row]`、`div:has([data-json-root-row])`、
  `[data-sidebar-right-guide] > span[aria-hidden='true']`）。

## 磨砂玻璃

五个面是磨砂的，而且**每一层模糊都挂在空的伪元素上**，从不挂在容器本体：侧栏、右栏、
输入卡、顶栏与会话列各自带一层 `::before`。给容器本体加 `backdrop-filter` 会让它成为
`position: fixed` 后代的包含块 —— 而设置面板就渲染在侧栏子树里。实测：
**全页 0 个元素**带 `backdrop-filter`，五层玻璃的模糊全部读自伪元素。

## 工作区 = 一张索引表

侧栏的 Workspaces 那一块按图纸索引排。一个工作区是一张**图签**：3px 墨线起头、等宽名号、
发丝线框；展开的那一张换成纸底 + 实墨左缘。它的会话挂在一条连续的 1px 竖轨上（行与行紧挨着，
所以每行左缘的内阴影连成一条线），行尾的值落在一道细线上；当前会话在那条轨上亮起 3px 墨线。

## 背景

首屏**不画任何东西** —— 画面交给视频本身。视频是一段 6.33s 的无缝循环，1920×1080 / 30fps：
源片 7.035s，把尾部 0.7s 与头部 0.7s 交叉淡入，于是回接处是原片的**连续两帧**
（实测回接差 0.56，全片帧间均差 1.80）。玻璃刻意做得很薄 —— 面板可读靠的是背后被模糊掉的
画面，不是靠不透明度。

这段视频是**来自互联网的第三方素材**，也是本目录里唯一不是作者原创的文件。它知道的部分
（来源、未识别到的权利人）与收录依据都记在 `NOTICE` 里；`LICENSE`（CC0 1.0）只覆盖皮肤
自身的代码与样式，不覆盖这段视频。

## 配色

- 底：深潭 `#071310`
- 墨：近白 `#e9f2ed`（暗底上，发丝线才是**亮**的那个东西）
- 水玉：`#6fd3b0` —— 只走线与字，不铺面
- 警示：`#e0685c` —— 全套唯一的红，只留给审批

## 预览

`preview/light.jpg` 是**浅色宿主系统**下的渲染，`preview/dark.jpg` 是深色宿主下的 ——
两次独立抓拍（市场模拟器，1440×900），不是同一个文件复制两遍。它们看起来一样，是因为
本皮肤按设计就是暗色专用；上面那条逐像素测量才是这个说法的依据。背景是一段循环视频，
所以两张抓拍落在不同的水面帧上。
